# Learning Commands

Before milestone design, task creation, task planning, or milestone review, read the Project
Learning Index first and then only relevant Learning Entry documents. Cite entries that influence
the result, or state that no relevant learning applied.

- `learning review`: read-only summary grouped by tag and impacted area.
- `learning apply`: read-only planning aid that converts applicable entries into concrete
  considerations while retaining citations and applicability limits.
- `learning organize`: draft merges, retags, archival, and index cleanup. Obtain approval before
  changing any document.

Keep milestone appendices compact. Store full reusable findings in Learning Entry documents and
use the Project Learning Index as their durable discovery point. Do not generalize a milestone
observation without source evidence and explicit applicability boundaries.
